Pengaturan Layout & Margin

Atur halaman agar surat terlihat profesional!

📋 Apa itu Layout?

Layout adalah pengaturan tata letak halaman dokumen, termasuk ukuran kertas, orientasi, dan margin (batas tepi). Layout yang tepat membuat surat mudah dibaca dan terlihat profesional!

📄 Ukuran Kertas Standar

✅ A4 (Paling Umum)

21 cm × 29.7 cm

Standar internasional, paling sering digunakan

✅ Folio / F4

21.5 cm × 33 cm

Populer di Indonesia untuk surat resmi

Letter

21.6 cm × 27.9 cm

Standar Amerika, jarang digunakan di Indonesia

⚙️ Cara Mengatur Ukuran Kertas:

  1. Klik tab Layout / Page Layout
  2. Klik Size
  3. Pilih A4 atau Folio

🔄 Orientasi Halaman

Text

✅ Portrait (Tegak)

Untuk surat resmi standar

Kapan digunakan? Semua surat resmi, dokumen formal, laporan

Text

Landscape (Mendatar)

Untuk tabel lebar

Kapan digunakan? Tabel data, grafik, presentasi (bukan untuk surat resmi)

⚙️ Cara Mengatur Orientasi:

  1. Klik tab Layout
  2. Klik Orientation
  3. Pilih Portrait

Margin kiri lebih lebar (4 cm) untuk dijilid tanpa menutupi teks

Memberikan ruang visual agar mata tidak cepat lelah

🛠️ Langkah Mengatur Margin di MS Word

1

Buka Tab Layout

Klik menu Layout atau Page Layout di ribbon

2

Klik Margins

Cari dan klik tombol Margins

3

Pilih Custom Margins

Klik Custom Margins... di bagian bawah

4

Atur Nilai Margin

• Top: 3 cm

• Left: 4 cm ⭐

• Right: 3 cm

• Bottom: 3 cm

5

Klik OK

Margin akan otomatis diterapkan ke seluruh dokumen

✅ DO (Lakukan)
  • ✓ Gunakan margin standar (Top/Right/Bottom: 3cm, Left: 4cm)
  • ✓ Periksa margin sebelum mencetak
  • ✓ Gunakan orientasi Portrait untuk surat
  • ✓ Pilih ukuran kertas A4 atau Folio
❌ DON'T (Jangan)
  • ✗ Membuat margin terlalu kecil (<2cm)
  • ✗ Margin kiri sama dengan yang lain
  • ✗ Menggunakan orientasi Landscape untuk surat
  • ✗ Lupa mengatur margin sebelum menulis

⚡ Shortcut Cepat:

Alt + P + M

Buka pengaturan Margins

Alt + P + S + Z

Buka pengaturan Page Size

Tabulasi untuk Surat Rapih

Rahasia surat resmi terlihat profesional!

🤔 Apa itu Tabulasi?

Tabulasi adalah fitur di MS Word untuk mengatur posisi teks secara presisi. Dengan tabulasi, kita bisa membuat teks sejajar dengan rapi tanpa menekan spasi berkali-kali!

💡 Tips Penting:
1.

Jangan gunakan spasi untuk menyejajarkan teks di surat resmi

2.

Selalu gunakan Tab untuk hasil yang konsisten dan profesional

3.

Atur tab stop sekali, lalu gunakan tombol Tab untuk semua baris

4.

Periksa alignment dengan melihat posisi tanda titik dua

📝 Langkah Membuat Tabulasi di MS Word

1

Aktifkan Ruler

Klik menu View → centang Ruler

2

Pilih Jenis Tab

Klik tombol tab di pojok kiri ruler untuk memilih jenis tab

3

Tentukan Posisi Tab

Klik pada ruler di posisi yang diinginkan

4

Gunakan Tab

Tekan tombol Tab untuk memindahkan kursor ke posisi tab

Header & Footer (Kop Surat)

Buat kop surat profesional dengan mudah!

⬆️ Apa itu Header?

Header adalah area di bagian atas halaman yang muncul di setiap halaman dokumen. Cocok untuk membuat kop surat!

📍 Area Header

NAMA INSTANSI

Alamat Lengkap

Isi Dokumen

🛠️ Cara Membuat Header:
  1. 1 Klik tab Insert
  2. 2 Klik Header
  3. 3 Pilih Blank atau template
  4. 4 Ketik kop surat
  5. 5 Double-click di luar untuk keluar

���️ Apa itu Footer?

Footer adalah area di bagian bawah halaman. Biasa digunakan untuk nomor halaman atau informasi tambahan.

Isi Dokumen

📍 Area Footer

💡 Tips Kop Surat yang Bagus:
  • ✓ Gunakan logo instansi di sebelah kiri
  • ✓ Nama instansi dengan huruf kapital & bold
  • ✓ Tambahkan garis horizontal di bawah kop
  • ✓ Sertakan alamat, telp, email, website
